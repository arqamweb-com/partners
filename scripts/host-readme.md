# نسخة الاستضافة

هذا المجلد **مُولَّد** بأمر `npm run host` ويُعاد بناؤه من الصفر في كل مرة.
لا تعدّل فيه شيئًا — عدّل في المصدر ثم أعد التوليد.

```
host/
├── public_html/     ← يُرفع كما هو إلى جذر النطاق الفرعي
└── database/        ← يُستورد من phpMyAdmin — لا يُرفع على السيرفر
```

---

## ماذا يُرفع ولماذا

| الملف / المجلد | وظيفته |
|---|---|
| `index.html` + `assets/` | التطبيق بعد البناء — ملفات ثابتة يقدّمها أباتشي |
| `favicon.ico` · `robots.txt` | أيقونة التبويب وتعليمات محركات البحث |
| `.htaccess` | **حرج**: يوجّه كل المسارات إلى `index.html`. بدونه تحديث أي صفحة داخلية يعطي 404 |
| `api/index.php` | نقطة الدخول الوحيدة للـ API |
| `api/lib/` | المنطق: الصلاحيات، قواعد العمل، الاستعلامات، الملفات |
| `api/bin/admin.php` | إنشاء حسابات الأدمن من السيرفر |
| `api/storage/` | مخزن الملفات المرفوعة — محجوب عن المتصفح بـ `.htaccess` |
| `api/.htaccess` | يوجّه `/api/*` إلى `index.php` ويمنع تحميل ملفات الإعداد |
| `api/.user.ini` | حدود الرفع: 8 ميجا للملف و12 للطلب |
| `api/config.example.php` | قالب بيانات الاتصال — **انسخه إلى `config.php` على السيرفر** |

> الملفات التي تبدأ بنقطة مخفية. فعّل `Show Hidden Files` في File Manager
> أو أظهرها في برنامج الـ FTP قبل الرفع، وإلا لن يعمل التطبيق.

---

## ما لا يُرفع — وسبب استثنائه

| العنصر | السبب |
|---|---|
| `src/` | شيفرة المصدر — تتحوّل إلى `assets/` عند البناء |
| `node_modules/` | أدوات البناء فقط، والسيرفر لا يشغّل Node أصلًا |
| `dist/` | مصدر `public_html/` هنا، فلا داعي لرفعه مرتين |
| `api/config.php` | يحمل كلمة مرور قاعدة البيانات — يُنشأ على السيرفر يدويًا |
| `api/storage/uploads/*` | ملفات تجربة محلية |
| `db/` | يُستورد من phpMyAdmin لا عبر الرفع |
| `package.json` · `vite.config.ts` · `tsconfig.json` · `eslint.config.js` | إعداد أدوات التطوير |
| `scripts/` | سكربتات بناء تعمل على جهازك |

## خطوات النشر

### 1. قاعدة البيانات
من `MySQL® Databases` أنشئ قاعدة ومستخدمًا بصلاحية `ALL PRIVILEGES`،
ثم من `phpMyAdmin` ← `Import` استورد بالترتيب:

1. `database/1-schema.sql`
2. `database/2-seed.sql`
3. `database/3-triggers.sql` — اختياري، غيّر خانة `Delimiter` إلى `$$`

`database/migrations/` للترقية فقط ولا تحتاجه في التنصيب الجديد.

### 2. الرفع
ارفع **محتويات** `public_html/` إلى جذر النطاق الفرعي.

### 3. الاتصال
على السيرفر: انسخ `api/config.example.php` إلى `api/config.php` واملأ بيانات
قاعدة البيانات، مع `'secure' => true` و`'debug' => false`.

### 4. حساب الأدمن
```sh
php api/bin/admin.php create you@site.com "اسمك"
```
من `Terminal`، أو من `Cron Jobs` مهمة تعمل مرة واحدة — حينها تُولَّد كلمة
مرور عشوائية وتظهر في ناتج المهمة.

### 5. التأكد
افتح `https://نطاقك/api/health` — يجب أن يرجّع `"ok": true`، وأن يكون
`php_post_max` أكبر من `8M`.

التفاصيل الكاملة في `README.md` بجذر المشروع.
